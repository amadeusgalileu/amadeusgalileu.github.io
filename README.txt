TOCA — Amadeus Galileu | Version 8 | English site

PREVIEW
Open index.html in a browser. Click EDITORIAL or OVERVIEW to switch views.
Open overview.html to start in the overview grid.
The 132 PDF pages retain their original layouts in consecutive pairs; no special rotations or repositioning.

MUSIC
The ♪ OFF button opens a link to the official Sacrifice video.
To play music directly inside the site, place an appropriately licensed file called music.mp3 in this folder.
A music file is not included and the website must not host copyrighted audio without permission.

PUBLISH ON GITHUB PAGES
1. Sign in to github.com and create a PUBLIC repository, e.g. toca-portfolio.
2. Select Add file > Upload files. Upload all the CONTENTS of this folder, not the ZIP itself, preserving the images folder.
3. Commit the files to the main branch.
4. Go to Settings > Pages > Build and deployment: Deploy from a branch > main > /(root) > Save.
5. Wait for the Pages URL shown under Settings > Pages.
6. When a domain has been purchased, add it under Pages > Custom domain, then configure DNS at the registrar according to GitHub Pages instructions.

NOTES
To add editorial notes later, edit the NOTES object near the top of script.js, keyed by original PDF page number.
